本次更新

- Android 安装包内置食物识别模型及运行库，首次拍照识别无需另外下载模型。
- 移除“首次需下载约150MB模型”和下载模型按钮，改为直接识别照片。
- 优化统一角色模型，10项动作采用一张静态关键姿势图，配合动作文字要点；其余5项保留分解演示。
- 增加角色多视角参考，可查看正面、侧面、背面与斜侧细节。
- App 新增“更新”入口，支持检查GitHub新版、查看更新说明、下载进度与系统确认安装；自动检查发现新版时显示提示。
- 修复Android本地模块与WASM响应类型，打包前后校验离线资源完整性。

使用说明

- 安装包已包含离线模型，因此文件比旧试用版更大。网页版识别仍需联网。
- 照片只在本机处理，食物种类、实际份量和烹调用油仍需确认。
- 当前仍为试用版本。旧版调试签名可能与新包不同；若系统提示签名不一致，请保留原App与其中记录，不要直接卸载。
- 应用内更新不会静默安装，手机会要求用户确认安装及来源权限。
